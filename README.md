# SpendWise Budget Tracker

## Project Description
SpendWise is an interactive budgeting application built using HTML, CSS, and JavaScript. It helps users manage their money by setting budgets, recording expenses, and tracking their remaining balances.

## Improvements Made This Week
This week, I improved SpendWise by adding JavaScript functionality, including conditional statements, arrays, loops, DOM manipulation, and event listeners.

Users can now enter their budgets, add multiple expenses, and view updated financial information on the dashboard.

## Conditional Statements
I used if, else if, and else statements to check whether users are within their budget, have used their entire budget, or have exceeded their budget.

## Arrays
I used an array called expenses to store multiple expense records. Each record contains an expense name and amount.

## Loops
I used for loops to calculate total expenses and display all recorded expenses on the dashboard.

## DOM Manipulation
I used document.getElementById() and textContent to update the total budget, total expenses, remaining balance, and feedback messages dynamically.

## Event Listeners
I used addEventListener() to respond when users click the Set Budget and Add Expense buttons.

## Challenges and Solutions
One challenge was connecting JavaScript to HTML elements. I addressed this by using matching element IDs and document.getElementById().

Another challenge was calculating multiple expenses. I solved this by storing expenses in an array and using a loop to calculate the total.

## Technologies Used
- HTML

- JavaScript

## Conclusion
This project helped me understand how JavaScript can make decisions, manage data, process records, update webpages, and respond to user interactions.
